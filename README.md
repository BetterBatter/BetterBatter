# PITCH9 UI Mockup

실시간 야구 경기 데이터, 구장 인증, 무료 포인트 예측, Oracle 검증과 블록체인 정산 흐름을 하나의 실행 가능한 UI로 만든 목업입니다.

기본 테마는 따뜻한 크림색 스코어카드와 딥 네이비 스포츠 헤더를 사용하는 라이트 모드입니다.

## 실행

```bash
pnpm install
pnpm dev
```

프로덕션 빌드는 `pnpm build`로 확인할 수 있습니다.

## 포함된 인터랙션

- 라이브 경기 및 이닝/주자/카운트 상황판
- 마켓 선택과 확률 변화 표시
- YES/NO 선택, 포인트 프리셋, 주문 처리/성공 상태
- 다음 투구 시연
- 내 예측, Oracle/온체인 검증 기록 화면
- 데스크톱/태블릿/모바일 반응형 레이아웃
